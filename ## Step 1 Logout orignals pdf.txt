## Step 1: Logout Old GitHub Account From VS Code

Open **VS Code Terminal** and run:

```bash
git config --global --unset user.name
git config --global --unset user.email
```

Now remove old GitHub login credentials.

### On Windows:

1. Press `Windows + S`
2. Search → **Credential Manager**
3. Open it
4. Go to **Windows Credentials**
5. Remove all entries related to:

   * GitHub
   * git:[https://github.com](https://github.com)

---

## Step 2: Create/New Login to GitHub

Go to:

[GitHub Official Website](https://github.com?utm_source=chatgpt.com)

Create your new account and verify email.

---

## Step 3: Configure New GitHub Account in VS Code

Open terminal in VS Code and run:

```bash
git config --global user.name "YourNewGitHubUsername"
git config --global user.email "yournewemail@gmail.com"
```

Example:

```bash
git config --global user.name "krushnabeldar22-blip"
git config --global user.email "krushnabeldar22@gmail.com"
```

---

## Step 4: Check Configuration

Run:

```bash
git config --global --list
```

You should see:

```bash
user.name=YourNewGitHubUsername
user.email=yournewemail@gmail.com
```

---

## Step 5: Login GitHub in VS Code

### Method 1 (Easy Method)

1. Open VS Code
2. Click Accounts icon (bottom left)
3. Click **Sign in with GitHub**
4. Browser will open
5. Login using new GitHub account
6. Authorize VS Code

---

## Step 6: Create New Repository on GitHub

1. Open:

[Create New GitHub Repository](https://github.com/new?utm_source=chatgpt.com)

2. Enter:

   * Repository Name
   * Public/Private
3. Click **Create Repository**

## Step 7: Push Existing Project to New GitHub Account

Open your project folder in VS Code.

Run commands one by one:

```bash
git init
```

```bash
git add .
```

```bash
git commit -m "first commit"
```

Now connect your new GitHub repo:

```bash
git remote add origin https://github.com/krushnabeldar22-blip/my
```

Example:

```bash
git remote add origin https://github.com/krushnabeldar22-blip/myproject.git
```

---

## Step 8: Push Code

```bash
git branch -M main
```

```bash
git push -u origin main
```

---

# If You Get Permission Error (403)

Run:

```bash
git remote -v
```

Remove old remote:

```bash
git remote remove origin
```

Add new remote again:

```bash
git remote add origin https://github.com/NEW_USERNAME/REPOSITORY_NAME.git
```

Then push again:

```bash
git push -u origin main
```
