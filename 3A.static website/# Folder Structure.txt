# Working of Application

1. User opens browser
2. Request goes to Node.js server
3. Express serves static files from `public` folder
4. HTML, CSS, and JS are loaded in browser
5. Website is displayed

---

# Advantages

* Fast web server
* Easy static file hosting
* Lightweight application
* Simple routing
* Cross-platform support

# Conclusion

This Node.js application uses Express framework to serve a static website. The server delivers HTML, CSS, and JavaScript files from the public folder and displays the webpage in the browser successfully.
