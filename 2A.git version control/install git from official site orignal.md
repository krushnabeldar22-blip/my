**# GitHub Version Control Account**



**GitHub is a version control platform used to store, manage, and track source code projects using Git.**



**---**



**# Steps to Create GitHub Account**



**## Step 1: Open GitHub Website**



**Go to:**



**\[GitHub Official Website](https://github.com?utm\_source=chatgpt.com)**



**---**



**## Step 2: Click “Sign Up”**



**\* Click on \*\*Sign up\*\***

**\* Enter:**



&#x20; **\* Email address**

&#x20; **\* Password**

&#x20; **\* Username**



**---**



**## Step 3: Verify Account**



**\* Complete CAPTCHA verification**

**\* Verify email using OTP/email link**



**---**



**## Step 4: Login to GitHub**



**After account creation:**



**\* Click \*\*Sign In\*\***

**\* Enter username and password**



**---**



**# What is Version Control?**



**Version control is a system that helps developers:**



**\* Track code changes**

**\* Store project history**

**\* Work in teams**

**\* Restore old versions**

**\* Manage project updates**



**---**



**# Benefits of GitHub**



**| Feature       | Use                              |**

**| ------------- | -------------------------------- |**

**| Repository    | Stores project files             |**

**| Commit        | Saves changes                    |**

**| Branch        | Creates separate working version |**

**| Push          | Upload code to GitHub            |**

**| Pull          | Download updated code            |**

**| Collaboration | Team project work                |**



**---**



**# Install Git Software**



**Download Git from:**



**\[Git Download Page](https://git-scm.com/downloads?utm\_source=chatgpt.com)**



**Install Git with default settings.**



**---**



**# Check Git Installation**



**Open Command Prompt and type:**



**```bash**

**git --version**

**```**



**Example Output:**



**```bash**

**git version 2.45.1**

**```**



**---**



**# Configure Git**



**```bash**

**git config --global user.name "Your Name"**



**git config --global user.email "your@email.com"**

**```**



**---**



**# Create New Repository on GitHub**



**1. Login to GitHub**

**2. Click \*\*New Repository\*\***

**3. Enter repository name**

**4. Click \*\*Create Repository\*\***



**---**



**# Git Commands for Uploading Project**



**## Initialize Git**



**```bash**

**git init**

**```**



**## Add Files**



**```bash**

**git add .**

**```**



**## Commit Files**



**```bash**

**git commit -m "First Commit"**

**```**



**## Connect GitHub Repository**



**```bash**

**git remote add origin REPOSITORY\_LINK**

**```**



**Example:**



**```bash**

**git remote add origin https://github.com/username/project.git**

**```**



**## Push Code to GitHub**



**```bash**

**git push -u origin main**

**```**



**---**



**# Workflow of GitHub Version Control**



**1. Create project**

**2. Initialize Git**

**3. Add files**

**4. Commit changes**

**5. Push to GitHub**

**6. Track project history**



**---**



**# Advantages of Version Control**



**\* Backup of code**

**\* Easy collaboration**

**\* Change tracking**

**\* Error recovery**

**\* Multiple developers can work together**

**\* Secure cloud storage**
