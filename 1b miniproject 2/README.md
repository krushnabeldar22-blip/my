# Exam Registration Portal Mini Project

A polished school exam registration site with AJAX-style submission and a dedicated roster page.

## Features
- Student registration form for exam entries
- AJAX-style submission using a simulated POST request
- Separate student roster page to view registered entries
- Summary stats for total students, exam types, and latest entry
- Styled with modern glassmorphism and gradient effects
- Data persisted in `localStorage`

## Files
- `index.html` — registration portal layout
- `student-list.html` — roster page with student list and stats
- `styles.css` — fancy form and dashboard styling
- `script.js` — registration form submission logic
- `student-list.js` — roster loading and display logic

## Run
Open `index.html` in your browser, register students, then click "View Registered Students".
